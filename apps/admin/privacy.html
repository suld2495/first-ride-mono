개인정보 처리방침

이루라가 어떤 정보를 수집하고, 어디에 사용하며, 어떻게 보호하는지 안내합니다.

시행일 2026.08.02

사용 데이터 분석 설정 Microsoft Clarity와 Firebase Analytics는 이루라 앱의 개인정보 처리방침 화면에서 각각 언제든 끌 수 있습니다. 끈 분석 도구는 이후 데이터 수집을 중지합니다.

01 총칙

이 방침은 개인 운영자(이하 “운영자”)가 모바일 애플리케이션 ‘이루라’(이하 “서비스”)를 제공하면서 처리하는 개인정보의 항목, 목적, 보유기간과 이용자의 권리를 안내하기 위해 마련되었습니다.

02 수집하는 개인정보 항목 및 방법

2-1. 회원가입 및 인증

  • 일반 회원: 이메일 주소(사용자 ID), 비밀번호, 닉네임, 직업
  • 소셜 회원: 로그인 제공자, 제공자가 발급한 사용자 식별정보와 인증 정보, 닉네임, 직업
  • 비밀번호는 인증을 위해 서버로 전송되며 복원할 수 없는 형태로 처리합니다. 소셜 access token은 로그인·가입 처리 중에만 사용합니다.

2-2. 서비스 이용

  • 설치 기기 ID, 기기 유형과 OS, 푸시 토큰 및 알림 설정
  • 루틴, 목표, 수행 기록, 친구 관계와 요청, 퀘스트, 통계·보상 정보
  • 사용자가 등록한 한마디, 사용자 이미지, 인증 요청 이미지
  • 문의 시 답변 받을 이메일, 문의 제목과 내용

2-3. 선택적 분석 데이터

  • Microsoft Clarity는 화면 이용 흐름, 탭·스크롤, 세션 및 기기·앱의 기술 정보를 수집합니다.
  • Firebase Analytics는 앱 실행, 세션, 자동 수집 이벤트 및 기기·앱의 기술 정보를 수집합니다.
  • 두 분석 도구는 신규 설치에서 기본적으로 켜져 있으며, 사용자는 앱 내 개인정보 처리방침 상단의 사용 데이터 분석 설정에서 각각 켜거나 끌 수 있습니다.
  • 서비스는 Clarity와 Firebase Analytics에 이메일, 사용자 ID, 닉네임, 비밀번호, 인증 토큰 등 직접 식별정보를 전송하지 않습니다.

2-4. 수집 방법

  • 회원가입·로그인 및 서비스 이용 중 사용자가 직접 입력하거나 이미지 선택·공유 기능으로 제출
  • 알림 권한 허용 후 푸시 토큰 생성, 앱 실행과 API 요청 과정에서 기기 정보 생성
  • 앱 실행 후 Clarity SDK와 Firebase Analytics SDK를 통한 자동 수집. 사용자가 각 분석 도구를 끄면 해당 SDK의 수집을 중지

03 개인정보 이용 목적

  • 회원가입, 로그인, 계정 관리와 부정 이용 방지
  • 루틴·친구·퀘스트·통계·보상 등 서비스 기능 제공
  • 인증 요청 이미지 처리와 사용자 맞춤 화면 제공
  • 푸시 알림 발송과 알림 설정 관리
  • 문의 접수, 답변과 운영 공지
  • 앱 사용성·오류·성능 분석 및 서비스 개선

04 개인정보 제3자 제공

  • 운영자는 이용자의 개인정보를 별도 동의 없이 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다.
  • 소셜 로그인, 푸시 알림, 분석 기능을 이용할 때에는 이용자가 선택한 기능 수행에 필요한 정보가 해당 서비스 제공자에게 전송될 수 있습니다.
  • 법령에 근거가 있거나 적법한 절차에 따른 요청이 있는 경우에는 관계 법령에 따라 제공할 수 있습니다.

06 보유 및 파기

  • 계정 및 서비스 이용 정보: 회원 탈퇴 시까지
  • access token·refresh token: 로그아웃, 회원 탈퇴 또는 토큰 만료 시까지
  • 푸시 토큰: 알림 해제, 로그아웃 또는 회원 탈퇴 시까지
  • 문의 정보: 문의 처리 목적 달성 시까지
  • Clarity 분석 정보: Microsoft Clarity 프로젝트에 설정된 보유기간 동안
  • Firebase Analytics 분석 정보: Google Firebase Analytics 정책과 프로젝트 설정에 따른 보유기간 동안
  • 관계 법령상 보존 의무가 있는 경우에는 해당 기간 동안 분리 보관한 뒤 파기합니다.
  • 전자파일은 복구하기 어려운 방법으로 삭제합니다.

07 이용자 권리 및 행사 방법

  • 앱 설정에서 계정 정보를 확인하고 회원 탈퇴를 요청할 수 있습니다.
  • Microsoft Clarity와 Firebase Analytics는 앱 내 개인정보 처리방침 상단의 사용 데이터 분석 설정에서 각각 언제든 켜거나 끌 수 있습니다. 끈 분석 도구는 현재 수집을 중지하고 다음 실행에서도 꺼진 상태를 유지합니다.
  • 개인정보 열람·정정·삭제·처리정지는 irura@gmail.com으로 요청할 수 있습니다.

08 개인정보 자동수집 장치

  • 신규 설치에서는 Clarity와 Firebase Analytics가 기본적으로 켜져 있습니다.
  • 두 분석 도구는 각각 켜거나 끌 수 있으며, 한쪽 설정은 다른 쪽에 영향을 주지 않습니다.
  • 사용자가 분석 도구를 끄면 해당 도구의 이후 데이터 수집을 중지합니다.

09 개인정보 보호조치

  • 인증 토큰은 기기의 보안 저장소에 보관합니다.
  • 통신 구간을 보호하고, 개인정보 접근 범위를 서비스 제공에 필요한 수준으로 제한합니다.
  • 비밀번호와 인증 토큰을 분석 이벤트나 로그의 사용자 식별값으로 사용하지 않습니다.
