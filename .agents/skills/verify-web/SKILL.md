# 웹 UI 요구사항 검증

Playwright MCP를 통해 브라우저를 직접 조작하며 요구사항이 실제로 충족되는지 확인한다.

**핵심 원칙:** 코드가 아닌 동작을 검증한다. 사용자 시각에서 기능이 작동하는지를 확인한다.

## 언제 사용하는가

- 웹 UI 기능 구현 후 요구사항 충족 여부 확인
- 사용자 흐름(로그인, 폼 제출, 페이지 이동 등) 검증
- 에러 상태 및 경계 조건이 UI에서 올바르게 표시되는지 확인

## 요청 방법

**1. verify 서브에이전트 실행:**

Task 도구를 사용해 `web-verifier.md` 템플릿을 verify 서브에이전트에게 전달한다.

**플레이스홀더:**
- `{REQUIREMENTS}` — 검증할 요구사항 (user story 또는 기능 명세)
- `{APP_URL}` — 앱 접속 URL
- `{DESCRIPTION}` — 무엇을 검증하는지 간단한 요약

**2. 결과 반영:**
- 실패 항목은 즉시 수정 후 재검증
- 통과 항목은 완료로 기록

## 예시

```
[로그인 기능 구현 완료]

[verify-web 서브에이전트 실행]
  REQUIREMENTS: 사용자는 이메일과 비밀번호로 로그인할 수 있다.
                잘못된 비밀번호 입력 시 오류 메시지가 표시된다.
  APP_URL: http://localhost:3000
  DESCRIPTION: 로그인 성공/실패 흐름 검증

[서브에이전트 결과]:
  통과: 올바른 자격증명으로 로그인 성공 후 대시보드 이동 확인
  실패: 오류 메시지가 표시되지 않음 — LoginForm.tsx:42
  판정: 일부 실패

[수정 후 재검증]
```
